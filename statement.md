# Patient Data Monitoring System

## Problem Statement
Managing basic patient healthcare information manually can be time-consuming and difficult to organize. Patient details, appointments, vaccination records, and health-check information may be stored separately, making it difficult to retrieve and monitor information efficiently.
The proposed Patient Data Monitoring System provides a simple Python-based solution for organizing these records. The system allows users to manage patient information, appointments, vaccinations, health checks, and reports through a menu-driven interface.

## Project Scope
The scope of the project is to provide basic healthcare record-management functionality using Python and text-file storage. The system focuses on maintaining patient records, managing appointments, recording vaccinations, identifying due vaccinations, storing basic health measurements, calculating BMI, and generating summary reports.
The project is designed as an educational prototype and does not provide medical diagnosis or replace professional healthcare systems.

## Target Users
The primary target users of this project are:
* Students learning Python programming
* Academic project evaluators
* Users demonstrating basic healthcare record management
* Small-scale educational healthcare applications

## High-Level Features

The system provides the following high-level features:
* Patient Management: Add, view, search, and update patient records.
* Appointment Management: Book, view, search, and cancel appointments.
* Vaccination Management: Add, view, and search vaccination records and identify vaccinations that are due.
* Health Check Management: Store basic health measurements such as height, weight, blood pressure, and blood sugar.
* BMI Calculation: Calculate BMI using the patient's height and weight and display the corresponding BMI category.
* Report Generation: Generate summaries for patients, appointments, vaccinations, and health checks.
* File-Based Data Storage: Store records persistently using separate text files.
* Menu-Driven Interface: Provide a simple command-line interface for accessing all system modules.
* Modular Architecture: Organize the application into separate Python modules for easier development, testing, and maintenance.


## Expected Outcome

The expected outcome of the project is a functional menu-driven Python application that can manage basic healthcare records and generate useful summaries. The project also demonstrates the practical application of Python fundamentals and modular programming to a real-world problem.

## Future Scope

The system can be further enhanced by integrating a database, adding user authentication, developing a graphical user interface, implementing appointment reminders, providing automatic vaccination schedules, and generating detailed digital reports.
